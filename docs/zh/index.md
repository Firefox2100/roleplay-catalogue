# 角色扮演资源库

角色扮演资源库是一套开源、自托管的内容管理系统，面向 SillyTavern 及相关角色扮演资源。个人或团队可以用它建立自己的内容库，自行决定收录内容、发布规则和运行环境。

## 许可证与免责声明

角色扮演资源库采用 [GPL v3](https://www.gnu.org/licenses/gpl-3.0.en.html) 许可证。你可以在遵守许可证的前提下使用、修改和分发本软件。本软件按“现状”提供，不附带任何担保；使用者需自行承担运行和使用风险。

软件本身不附带任何内容，也不会替管理员进行内容审核。实例管理员应确保所托管的内容符合当地法律和自身规则。

## 功能特性

资源库同时服务于查找内容的用户、维护作品的作者以及负责运行实例的管理员。

- **支持 SillyTavern 角色卡**：用户可以创建、上传和下载 SillyTavern V3 格式角色卡。上传时 V2 格式卡会自动转换为 V3 格式。
- **支持 SillyTavern 世界书**：世界书作为独立资源类型，可从角色卡中链接，实现多张角色卡复用同一本设定书。
- **支持 SillyTavern 聊天预设**：用户可以创建、上传和下载聊天完成预设。
- **版本发布和派生**：作者可创建资源的新版本，用户可 Fork 现有资源创建衍生版本。这促进了资源的协作和共享，同时保持原作品的完整性。
- **搜索和筛选**：可以按关键词、标签、资源类型和作者查找内容。
- **协作编辑**：作者可邀请其他用户协作编辑资源，允许多个贡献者共同编辑同一资源。
- **使用统计**：资源列表和详情页会显示匿名浏览次数与下载次数。

### 角色卡

创建、上传和下载 SillyTavern V3 格式角色卡（导入时 V2 卡自动转换）。角色卡可内嵌世界书、PNG 封面图，并最多关联 50 本来自资源库的世界书。可 Fork 现有角色卡制作衍生版本。

- [详细指南](features/character-cards.md)

### 世界书

世界书可独立上传、编辑和发布，也可以关联到角色卡。发布角色卡时，选定的世界书内容会一同导出。

- [详细指南](features/lore-books.md)

### 聊天预设

SillyTavern 生成预设（温度、停止词、重复惩罚等），以 JSON 格式存储和共享。可 Fork 预设，调整参数后用于你的角色。

- [详细指南](features/chat-presets.md)

### 图片与封面

上传图片资源（PNG、JPEG、WebP、GIF）。为角色卡、世界书和世界数据包指定封面图片。图片发布后不可变，Fork 时按 SHA-256 哈希去重。

- [详细指南](features/images.md)

### WorldSE 数据包

上传和分享 WorldSE 兼容的 `.zip` 数据包。导入时嵌入式图片被提取为独立资源。可 Fork 世界数据包，基于现有设计衍生新的游戏设定。

- [详细指南](features/worlds.md)

### DeepSeek Harness Agentic Roleplay 世界

将 `dsh-agentic-roleplay` 的原生世界文件夹作为 ZIP 上传，发布后可直接下载安装，无需转换为 WorldSE。资源库会索引元数据、处理封面并生成文件清单差异；完整世界模型验证由 Harness 完成。

- [详细指南](features/agentic-roleplay-worlds.md)

### 版本管理与发布

角色卡、世界书、预设和两种世界格式使用草稿与发布流程。草稿可继续编辑；发布会创建带独立可见性、内容差异和存储文件的不可变快照。图片上传后即作为不可变资源，不单独发布。

- [详细指南](features/versioning.md)

### 资源 Fork（衍生）

Fork 有权读取的已发布角色卡、世界书、预设或世界，在你的账户下创建私有草稿。新资源保留源版本引用，并在 Fork 所有者的图片库内通过 SHA-256 匹配可复用封面。

- [详细指南](features/forking.md)

### 协作编辑

作者可邀请协作者编辑资源草稿。协作者可上传数据、修改元数据、链接 世界书；仅作者可发布或删除。

- [详细指南](features/collaborative-editing.md)

### 搜索与过滤

支持 MongoDB 文本搜索、标签 / 类型 / 作者筛选、分页、标签自动补全，并可按更新时间或热度排序。

资源卡片和详情页会显示匿名浏览与下载次数。打开资源详情会计为一次浏览；通过后端直接下载文件或生成签名下载链接会计为一次下载。

- [详细指南](features/search-and-filtering.md)

### 导入资源

导入现有 SillyTavern 内容、WorldSE 数据包和原生 Agentic Roleplay 世界 ZIP。角色卡和世界书会合并到草稿；预设和原生世界 ZIP 会替换对应的类型数据。

- [详细指南](features/importing-resources.md)
