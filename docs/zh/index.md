# 角色扮演资源库

角色扮演资源库是一个开源的角色扮演资源托管解决方案，适用于 SillyTavern 或类似框架的内容库。它与主流的商业平台不同，专注于提供私有或组织维护的资源库，将控制权完全交给部署者，并整合帮助用户、作者和更广泛社区的功能，而非专注于盈利和广告。

## 功能特性

本软件的核心理念是为角色扮演资源的作者、分发者和使用者提供便捷的功能。因此，软件的特性不断根据社区反馈和需求演进。部分已实现的功能包括：

- **支持 SillyTavern 角色卡**：用户可以创建、上传和下载 SillyTavern V3 格式角色卡。上传时 V2 格式卡会自动转换为 V3 格式。
- **支持 SillyTavern 背景设定书**：背景设定书作为一等资源类型，可从角色卡中链接，实现多张角色卡复用同一本设定书。
- **支持 SillyTavern 聊天预设**：用户可以创建、上传和下载聊天完成预设。市面上很少有为预设共享设计的平台，本软件致力于弥补这一空白。
- **版本发布和衍生复刻**：作者可创建资源的新版本，用户可 Fork 现有资源创建衍生版本。这促进了资源的协作和共享，同时保持原作品的完整性。
- **搜索和过滤**：用户可以按标签、分类、作者和评分等标准搜索资源，也可过滤结果找到最相关的内容。
- **协作编辑**：作者可邀请其他用户协作编辑资源，允许多个贡献者共同编辑同一资源。

### 角色卡

创建、上传和下载 SillyTavern V3 格式角色卡（导入时 V2 卡自动转换）。角色卡可内嵌 lorebook、PNG 封面图，并最多关联 50 本来自资源库的 lorebook。可 Fork 现有角色卡制作衍生版本。

- [详细指南](features/character-cards.md)

### 背景设定书（Lorebook）

lorebook 可作为一等资源独立上传、版本化和链接。Lorebook 自包含，可从角色卡中链接（实时草稿或固定发布版），发布时设定书自动随角色卡一同导出。

- [详细指南](features/lore-books.md)

### 聊天预设

SillyTavern 生成预设（温度、停止词、重复惩罚等），以 JSON 格式存储和共享。可 Fork 预设，调整参数后用于你的角色。

- [详细指南](features/chat-presets.md)

### 图片与封面

上传图片资源（PNG、JPEG、WebP、GIF）。为角色卡、lorebook 和世界数据包指定封面图片。图片发布后不可变，Fork 时按 SHA-256 哈希去重。

- [详细指南](features/images.md)

### WorldSE 数据包

上传和分享 WorldSE 兼容的 `.zip` 数据包。导入时嵌入式图片被提取为独立资源。可 Fork 世界数据包，基于现有设计衍生新的游戏设定。

- [详细指南](features/worlds.md)

### 版本管理与发布

所有资源遵循**草稿 → 发布**流程。草稿可随时编辑；发布后生成不可变快照，拥有独立可见性、内容差异和 S3 制品。

- [详细指南](features/versioning.md)

### 资源 Fork（衍生）

Fork 任意已发布版本，在你的账户下创建一个衍生资源。封面图自动去重，lorebook 自动携带，Fork 默认私有方便安全编辑后再分享。

- [详细指南](features/forking.md)

### 协作编辑

作者可邀请协作者编辑资源草稿。协作者可上传数据、修改元数据、链接 lorebook；仅作者可发布或删除。

- [详细指南](features/collaborative-editing.md)

### 搜索与过滤

基于 MongoDB Community Search 的全文搜索，支持按标签 / 类型 / 作者筛选、分页、标签自动补全。

- [详细指南](features/search-and-filtering.md)

### 导入资源

导入现有 SillyTavern 内容 — 角色卡（JSON / PNG）、lorebook、预设和世界数据包。资源库通过**合并**策略将导入数据写入草稿，避免覆盖手工编辑的内容。

- [详细指南](features/importing-resources.md)
