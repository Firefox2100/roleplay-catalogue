# 图片与封面图

## 概述

角色扮演资源库支持图片的两种不同用途：

- **封面图** — 附加到角色卡、世界书、预设和世界数据包的视觉缩略图。这些图片会出现在搜索结果、资源卡片和列表页面中。
- **独立图片** — 在资源库中作为独立资源存在的图片，具备与所有其他资源类型相同的能力（名称、描述、标签、可见性、语言）。

资源库中存储的每张图片同时也是一个完整的**图片资源**。它可以被命名、描述、打标签、设置可见性和语言，并拥有版本历史追踪 — 就像角色卡或世界书一样。

## 使用方法

### 上传图片

1. 打开资源库的图片上传区域。
2. 选择 支持的格式的文件（PNG、JPEG、WebP 或 GIF）。
3. 上传操作会**自动创建图片资源**并发布该资源的**版本 1**。
4. 发布后该版本即不可变 — 不会再发生变化。如需替换图片，请上传新文件并选择为目标资源设置封面。

**最大上传大小：** 20 MiB。

### 为角色卡、世界书或世界设置封面图

1. 打开资源编辑器（例如角色卡编辑器）。
2. 找到**"选择封面图"**控件。
3. 浏览已上传图片并选择一个。
4. 保存资源 — 封面引用现在指向所选图片的最新已发布版本。

**注意：** 图片必须至少有一个已发布版本，才能被选作封面图。

### 导入角色卡时提取封面图

通过 PNG 导入 SillyTavern 角色卡时，资源库会自动从角色数据和嵌入的 tEXt 块中读取 `[cover_image]` 字段。如果在 PNG 中找到封面图，它会被提取并存储为独立图片资源，同时自动设置为卡牌封面。

### 下载与分发

- 每个图片资源提供一个**签名下载链接**，过期时间为 **120 秒**。
-资源库分发的公开图片使用 `Cache-Control: public, max-age=31536000, immutable`（一年），这是安全的，因为图片一旦发布即不可变。

### 删除图片

- 使用 `force=true` 可以删除图片，即使当前有资源正在将其用作封面图。被引用的资源中的封面引用会被自动清除。

### Fook 带有封面图的资源

当角色卡、世界书、预设或世界被 Fork 且包含封面图时：

-资源库会检查 Fork 作者（通过 SHA-256 哈希去重）是否已存在该图片的副本。
- 如果存在完全相同的副本，则复用现有副本。
- 否则，在 Fork 作者名下上传新副本，Fork 的封面指向该新副本。

## 限制

| 限制项 | 值 |
|--------|------|
| 支持的格式 | PNG、JPEG、WebP、GIF |
| 最大文件大小（`image_max_bytes`） | 20 MiB |
| 签名链接过期时间（`signed_url_expiry`） | 120 秒 |
| 封面图不可变性 | 发布后版本不可修改 |
| 图片必须已发布 | 须至少存在一个版本后才能作为封面 |

## 提示与注意事项

- **覆盖操作是增量式的。** 上传封面图的新版本不会删除旧版本 — 两个版本保留在资源库中。这使你可以在需要时回滚。
- **对可复用的图片使用独立上传。** 如果你知道同一张艺术图将作为多个角色卡或世界的封面，可以将其作为独立图片上传一次，然后从各资源中引用它。
- **签名链接是临时的。** 如需公开嵌入图片（例如在邮件或博客文章中），请使用直接公开 URL 端点而非签名下载链接。
- **基于 tEXt 块的提取。** 嵌入在 SillyTavern PNG 卡牌中的封面图从 `tEXt` ID 块（`[cover_image]`）中提取。如果卡牌是 PNG 但缺少该块，导入仍会创建角色卡资源，只是不会附加封面图。
- **对缓存友好。** 由于发布后的图片永不变更，其一年期的不可变缓存头部是安全的，并可帮助减少访问者的带宽成本。
