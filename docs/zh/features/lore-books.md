# SillyTavern 世界书

## 概述

SillyTavern 世界书是资源库的独立资源。你可以独立上传、编辑、版本化、Fork 和发布世界书，也可以将其关联到角色卡上，使 世界书数据随角色卡一起在发布时捆绑交付。

## 使用方法

### 创建世界书

世界书由一组**条目（entries）**构成，用于为角色提供游戏内上下文信息。每本资源库世界书最多可容纳 50 个条目。你可以通过上传表单创建世界书草稿内容，也可以从现有的 SillyTavern 世界书导入。

系统会自动检测上传的 JSON 文件使用的是当前 **`lorebook_v3`** 规范还是旧版 **V2** 格式，并分别进行解析。

### 导入世界书

你可以从以下三种来源导入世界书数据：

- **独立 JSON 文件** — 完整的 SillyTavern V2 或 V3 世界书文件。
- **嵌入角色卡 JSON 中** — 导入包含世界书区块的角色卡时，资源库会同时解析角色卡和其中的世界书。
- **嵌入 PNG 角色卡中** — 资源库会从 tEXt 块中与卡牌一并读取世界书数据。

### 合并行为

如果你向已有草稿条目的世界书资源导入数据，将使用与角色卡相同的合并策略：

- 保留现有条目，新条目追加到末尾。
- 类似字典的字段按键逐个合并。
- 导入数据中缺失的值会从现有草稿中填充。

如需完全替换所有内容，请先清空草稿。

### 从角色卡关联

每张角色卡的草稿都维护着一个**已关联世界书引用**的列表。对于每个关联项，你可以选择以下两种模式之一：

| 模式 | 行为 |
|------|------|
| **关联草稿（Link Draft）** | 编辑时可使用。发布角色卡前必须选定一个世界书发布版本。 |
| **关联已发布版本（Link Release Version）** | 固定角色卡使用的世界书发布版本。 |

角色卡发布时，所有关联的世界书都会**合并到编译后的 JSON 中**。发布用户无需单独导出或下载 世界书。

### 封面图

世界书可以设置封面图。通过编辑器的**封面图选择器**进行设置。封面图需满足标准图片上传要求（详见 [图片](images.md) 文档）。

### Fork

你可以对已发布的世界书进行 Fork。Fork 后的世界书会携带源版本的所有已关联世界书引用，便于构建 lore 扩展链。

## 限制

| 限制项 | 上限 |
|--------|------|
| 每个 世界书最大条目数 | 50 |
| 每张角色卡最多关联世界书 | 50 |
| 支持的世界书规范 | `lorebook_v3`（当前）、V2（旧版，自动检测） |
| 封面图最大大小 | 20 MiB |

## 提示与注意事项

- **发布前固定版本。** 角色草稿可以指向世界书草稿，但发布时必须选定具体的世界书发布版本，以便稳定重建角色文件。
- **删除保护。** 当前被角色卡链接的世界书无法从资源库中删除。必须先从角色卡上移除关联才能删除。
- **PNG 导入很方便。** 如果你的世界书嵌入在 PNG 角色卡中，一次上传即可获得两者 —非常适合分享完整的卡牌集合。
- **版本化是自动的。** 每次发布时，都会创建一个新的不可变版本并添加到版本历史中 — 你可以随时回滚或进行差异对比。
