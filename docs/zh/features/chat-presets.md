# SillyTavern 聊天预设

## 概述

Roleplay Catalogue 存储和分享**SillyTavern 聊天预设** — 模型专用的生成配置，定义温度（temperature）、最大 Token 数、停止序列（stop sequences）、重复惩罚（repetition penalty）以及其他采样器参数。预设让你能够与社区分享你偏好的生成配置，并快速切换不同风格的模型行为。

预设遵循标准 SillyTavern JSON 预设格式，是 Catalogue 中的一等资源。它们出现在搜索结果中，支持标签和可见性设置，可被 Fork、下载为 JSON，并带有语言标签。

## 使用方法

### 上传预设

1. 导航到 Catalogue 编辑器的预设上传区域。
2. 选择 SillyTavern 预设格式的 `.json` 文件。
3. 提供**名称**（必填，最多 200 个字符）和可选的**描述**（最多 10,000 个字符）。
4. 可选：添加**标签**、设置**可见性**等级并选择**语言**。
5. 提交上传。

上传的 JSON 会被解析并存储为预设资源的草稿数据。

### JSON 预览

每个已发布的预设都包含一个 JSON 预览面板。你可以在不下载预设包的情况下，通过可展开面板查看完整的生成配置。

### 导出预设

1. 打开预设详情页。
2. 点击**导出**按钮，将预设下载为 `.json` 文件。

导出功能支持四种资源类型：角色卡、Lorebook、预设和世界数据包。

### 创建 Fork

1. 打开任意已发布的预设。
2. 从预设操作菜单中选择 **Fork**。
3. Catalogue 会创建一个新的预设资源，包含你 Fork 时刻源预设的所有配置数据。
4. 按需编辑设置。这些更改仅出现在 Fork 中，原始预设保持不变。

### 搜索与过滤

预设与角色卡、Lorebook 和世界一起出现在通用搜索结果中。相同的过滤机制同样适用：

- **标签过滤** — 按预设的标签搜索。
- **可见性过滤** — 公开和未列出的预设在浏览视图中显示；私有预设仅对拥有者可见。
- **语言过滤** — 预设带有语言标签（简体中文或英文），基于其元数据。

### 导入行为

当你在已有草稿数据的现存资源上导入 SillyTavern 预设 JSON 时，导入的 JSON**会覆盖**现有草稿。如需在测试新更改之前保留现有草稿，请先下载当前草稿。

## 限制

| 限制项 | 上限 |
|--------|------|
| 最大文件大小（`preset_max_bytes`） | 5 MiB（5,242,880 字节） |
| 预设名称 | 必填，最多 200 个字符 |
| 预设描述 | 可选，最多 10,000 个字符 |
| 接受的格式 | SillyTavern 预设 JSON |
| 封面图 | 预设不支持封面图 |
| 语言 | 可选，按预设单独设置 |
| 可导出资源类型 | 仅角色卡、Lorebook、预设和世界数据包 |

## 提示与注意事项

- **小而强大。** 预设控制模型在生成过程中的行为。建议为不同角色或场景创建预设 — 例如使用较高温度参数的"创意"预设，以及需要一致性的"确定性"对戏预设。
- **修改前先 Fork。** Fork 已发布的预设可让你获得一个干净的起点。所有更改都会进入 Fork，原始预设不受影响。
- **仅支持 JSON 导出。** 只有上述四种列出的资源类型支持公开导出。请使用导出功能而非原始 API 来获取可用的 `.json` 文件。
- **导入即覆盖。** 导入新的 JSON 文件会完全替换草稿数据。如需以后参考，请先下载现有草稿。
- **无封面图。** 与角色卡和世界不同，预设不支持封面图。请使用描述性的名称和标签帮助用户发现你的预设。
