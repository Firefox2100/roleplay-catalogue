# DeepSeek Harness Agentic Roleplay 世界

角色扮演资源库可以保存和发布 `dsh-agentic-roleplay` 项目的原生世界文件夹。交换方式很直接：将世界文件夹压缩为 ZIP 后上传；下载时解压，再放入 Harness 的世界目录。

资源库会保留原始包结构，不会将它转换成 WorldSE 格式。这样能保留项目专有文件，也避免两种世界模型之间的有损转换。

## 准备 ZIP

压缩包必须只有一个顶层文件夹，其中必须直接包含 `world.json`。

```text
harbour-world/
  world.json
  characters/
  locations/
  media/
    manifest.jsonl
    ...
```

请压缩 `harbour-world` 文件夹本身，不要只压缩其中的文件。ZIP 中不能有第二个顶层文件夹，也不能在顶层混入其他文件。

导入器会在存储前检查压缩包。它会拒绝不安全路径、符号链接、加密条目、重复或大小写冲突的路径、格式错误的 UTF-8 JSON 和 JSONL，以及超出限制的压缩包。所有文件都保留在 ZIP 中，资源库不会执行包内容。

这些检查覆盖压缩包安全和文档语法。世界的完整领域验证仍由 DeepSeek Harness 在加载时完成。

## 上传和编辑

创建类型为 **DeepSeek Harness Agentic Roleplay 世界** 的资源，然后在编辑器中上传 ZIP。再次上传会替换草稿包，但不会改动已发布的版本。

编辑器会显示包内世界名、原生版本、作者、文件夹名、文件数和压缩大小。点击**使用包元数据**会把原生名称和描述复制到资源库字段，并合并原生标签。如果你希望使资源更容易被搜索，也可以保留不同的资源库元数据。

如果 `world.json` 没有 `id`，导入器会在规范化后的包中添加一个。如果它设置了 `cover_media_id`，导入器会通过 `media/manifest.jsonl` 查找对应文件，并为封面创建图片资源。

## 发布和比较版本

发布会保存规范化 ZIP 的不可变副本。每个版本都记录文件名、字节大小和 SHA-256 哈希。

版本差异来自已索引的文件清单，包括原生元数据以及每个文件的路径、大小和 SHA-256 变化。资源库不会对世界内部文档生成逐行语义差异。

## 安装下载的世界

下载指定版本并解压，将解压后的顶层文件夹放入 DeepSeek Harness Agentic Roleplay 安装所使用的 `worlds/` 目录。不要改变文件夹结构。Harness 会在加载世界时执行完整的领域验证。

## Fork

Fork 会从选定的已发布版本创建一个私有资源。新资源会获得新的世界 ID，因此可以和源世界同时安装在一个 Harness 环境中。其他包文件保持不变，资源库记录也会保留源版本引用。

## 限制

| 检查项 | 默认值或规则 |
|---|---|
| 压缩后上传大小 | 100 MiB，可通过 `RC_DSH_WORLD_MAX_BYTES` 配置 |
| 解包后大小 | 512 MiB |
| 压缩包条目 | 最多 5,000 个 |
| 目录结构 | 一个顶层文件夹，其中包含 `world.json` |
| 文件夹名 | 1 至 100 个 ASCII 字母、数字、点、下划线或连字符；首字符必须是字母或数字 |
| JSON | UTF-8 JSON 和 JSONL 文件必须能够正常解析 |
| 封面格式 | PNG、JPEG、WebP、GIF 或 AVIF |
