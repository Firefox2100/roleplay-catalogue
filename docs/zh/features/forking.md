# 资源 Fork（衍生）

**Fork（衍生）** 允许你为任何已发布资源创建一个衍生版本 — 归属你自己的账号，基于源资源的最新版本拥有可编辑的草稿。Fork 是社区内容在版本管理系统的 remix、改编和优化的基础。

## 概览

Fork 资源时，系统会执行以下操作：

1. **快照** 源资源最新的已发布版本。
2. 在你的账号下**创建**同类型的新资源。
3. **初始化** 可编辑草稿：数据来源为源版本的快照。

Fork 从创建的那一刻起就是你自己的资源 — 你可以编辑、重新命名或发布，不会影响原始资源。

## 如何 Fork

### 通过 UI

导航到任意可发布资源版本的详情页，点击**Fork**按钮。系统会即时生成一个新资源，并将你重定向到新资源的草稿编辑器。

### 通过 API

调用 Fork 端点，传入你想基于哪个版本进行 Fork：

```
POST /versions/{versionId}/fork
```

源版本必须对你的账号可读（公开、已登录用户可见，或私有且你拥有作者/协作者权限）。

## 复制的字段

| 字段 | 源 → Fork |
|---|---|
| 资源类型 | 完全相同（角色卡、Lorebook、预设或世界） |
| 草稿数据 | 版本数据的完整快照成为你的可编辑草稿 |
| `forkedFrom` | 记录原始 `resourceId` 和 `versionId` 作为引用链 |
| 名称 | 默认值：**"Forked from [源名称]"** — 可以自由重命名 |
| 标签 | 从源发布版本复制 |
| 描述 | 从源发布版本复制 |
| 关联 lorebook | 以完全相同的版本引用带入草稿 |
| 封面图 | 复制到你账号下（见下文去重说明） |
| 可见性 | 始终初始化为**私有**（不继承源版本的可见性） |

### 封面图去重

如果源版本的发布包含封面图，Fork 会通过比对该图片的 **SHA-256 哈希值**在你的账号下查找已有的副本。如果匹配的图片已存在于你的存储中，Fork 将直接复用。如果不存在副本，则将图片先上传到你的存储，然后由 Fork 引用。

Fork 发布后的制品存储在你自己的 S3 路径下：

```
releases/{your_resource_id}/{your_version_id}{extension}
```

## Fork 行为细节

### 仅可发布版本可 Fork

源版本必须是已发布的状态。原始资源上未发布的草稿更改**不**包含在内 — 仅有最新已发布的内容被复制到 Fork 的草稿中。

### Fork 可见性

无论源版本如何发布，Fork 始终初始化为**私有**状态。你可以随时更改草稿的可见性或任意版本的可见性。

### Fork 的版本链

发布 Fork 后，新版本的 `previousVersionId` 指向 Fork 的前一版本（如果有的话）。资源记录上的 `forkedFrom` 字段永久保留指向原始资源和原始版本的链接 — 此链不会被覆盖。

### 导出 Fork 的草稿

在发布之前，你可以像导出其他资源一样导出 Fork 的草稿：

- 角色卡：`.draft.json` 或 `.draft.png`（PNG 导出内嵌了卡片数据）
- Lorebook：`.draft.json`
- 预设：`.draft.json`
- 世界：`.draft.zip`

## 约束条件

| 约束 | 限制 |
|---|---|
| 支持的资源类型 | 角色卡、Lorebook、预设、世界 |
| 图片资源 | 不可 Fork（图片数据本质上是单一不可变上传） |
| 仅已发布版本 | 未发布的草稿更改不包含在内 |
| Fork 命名 | 默认自动生成；可以自由更改 |
| Fork 标签合并 | 标签原样复制；不对已有 Fork 标签进行去重 |

## 提示与注意事项

> [!TIP]
> **从你需要的版本发起 Fork。** 如果一个资源有多个已发布版本，请导航到特定版本页面然后从那里 Fork。系统 Fork 的是该精确版本的快照，而非最新版本。

> [!NOTE]
> **Fork 会留下贡献痕迹。** `forkedFrom` 引用构成了所有资源之间的有向无环图。你可以沿着祖先追溯 Fork 的原始来源，也可以向前发现衍生资源。此信息在详情页展示。

> [!NOTE]
> **关联的 lorebook 在 Fork 中保持不变。** 如果源角色卡引用了版本为 `abc123` 的 lorebook，你的 Fork 草稿将以完全相同的引用开始。之后你可以更新 lorebook 链接以指向不同版本。

## API 参考（开发者使用）

| 方法 | 端点 | 描述 |
|---|---|---|
| `POST` | `/versions/{versionId}/fork` | 从指定版本创建新的 Fork 资源 |
| `GET` | `/versions/draft/{resourceId}/download` | 导出 Fork 的未发布草稿 |
| `GET` | `/versions/{versionId}/download` | 下载 Fork 的已发布制品 |
