# 协作编辑（协作者）

协作者机制允许资源的**作者**邀请其他注册用户来编辑草稿。协作者共享完整的草稿编辑权限 — 上传数据、修改元数据、链接世界书和导出 — 但只有作者保留发布和删除权限。

## 概览

此功能适用于以下场景：

- **多人协作** 正在编写共享资源（例如多名社区成员展开的角色卡）。
- **补充与替换** 协作者添加内容（对话、趣味知识、扩展段落），作者审核后采纳。
- **世界书团队** 多名写作者向共享宇宙贡献条目。

### 权限对照表

| 操作 | 作者 | 协作者 | 其他用户 |
|---|---|---|---|
| 查看草稿 | 是 | 是 | 取决于可见性 |
| 编辑草稿数据 | 是 | 是 | 否 |
| 编辑元数据（名称、描述、标签） | 是 | 是 | 否 |
| 上传 / 更换封面图 | 是 | 是 | 否 |
| 链接 / 取消链接世界书 | 是 | 是 | 否 |
| 导出草稿 | 是 | 是 | 否 |
| 发布版本 | 是 | 否 | — |
| 删除资源 | 是 | 否 | — |
| 管理协作者列表 | 是 | 否 | — |
| 发布后修改版本可见性 | 是 | 否 | — |

## 如何添加协作者

1. 打开资源详情页或编辑页的**协作者**区域。
2. 输入要邀请用户的**精确用户名**。
3. 点击**添加协作者**。
4. 邀请即时生效 — 用户立即获得完整的草稿编辑权限。

## 如何移除协作者

作者可以在同一处移除任意协作者。

### 由协作者自己退出

协作者也可以自行退出。退出不会删除其此前已经写入草稿或发布历史的内容。

### 账号删除时

当用户删除其账号时，他们会被自动从所有资源的协作者列表中移除。该资源的作者保留完全控制权限。

## Fork 中的协作者贡献可见性

当协作者 Fork 其参与贡献的资源时，其个人贡献链是可见的：

- 其草稿编辑包含在 Fork 的数据中。
- Fork 发布的版本继承了合并后的数据快照。
- 已发布版本的 `contentDiff` 显示包含所有贡献者全部变更的统一差异。
- 在资源详情页，协作者与作者用户名一同列出。

## 约束条件

| 约束 | 限制 |
|---|---|
| 用户名格式 | 精确匹配，区分大小写 |
| 作者本身 | 不可将作者自身作为协作者添加（无重复） |
| 重复邀请 | 已经是协作者的用户不能重复添加 |
| 删除被链接的世界书 | 仅 世界书的作者可以删除它；角色卡的非作者协作者不能删除该 世界书 |
| 协作者数量 | 当前没有配置上限 |

## 提示与注意事项

> [!TIP]
> **审慎选择协作者。** 拥有协作者链接的用户均可编辑和导出草稿。如果内容敏感，建议在邀请外部协作者之前更改草稿的可见性。

> [!NOTE]
> **可见性相互独立。** 草稿可见性控制谁可以*查看*资源，协作者列表控制谁可以*编辑*草稿。一个公开资源内的私有协作者仍然获得编辑权限。

> [!NOTE]
> **协作者共享草稿权限。** 作者和协作者都能上传数据、修改元数据和导出草稿；发布、删除及管理协作者仍只允许作者操作。

> [!IMPORTANT]
> **标签顺序在跨协作者场景下得到保留。** 多名协作者追加标签时，最终标签列表反映添加顺序。重复标签由导入合并逻辑自动去重。
